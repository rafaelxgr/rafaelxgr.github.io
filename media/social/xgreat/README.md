# XGreat Social Media Library

Biblioteca pública de mídia usada pela operação social da XGreat.

Estrutura:
- `feed/` imagens individuais do feed
- `carousels/` imagens para carrosséis
- `stories/` imagens e vídeos de stories
- `reels/` vídeos e capas de reels

Os arquivos publicados neste diretório podem ser servidos pelo domínio `https://xgreat.com.br/media/social/xgreat/` e usados pelo Windsor.ai para publicação nas redes sociais.

## Padrão de nomes

Use nomes simples, em minúsculas, sem espaços e com data quando útil.

Exemplos:
- `2026-09-18-xgreat-os-feed.jpg`
- `2026-09-18-xgreat-os-01.jpg`
- `2026-09-18-xgreat-os-story.jpg`
- `2026-09-18-xgreat-os-reel.mp4`

Não armazenar documentos privados, credenciais ou dados de clientes neste diretório público.
